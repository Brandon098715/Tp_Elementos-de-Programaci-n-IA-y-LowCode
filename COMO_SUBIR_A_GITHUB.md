# Cómo subir estos archivos a la rama interfaz-grafica

1. Entrar al repositorio en GitHub.
2. Verificar arriba a la izquierda que la rama seleccionada sea `interfaz-grafica`.
3. Presionar **Add file**.
4. Elegir **Upload files**.
5. Descomprimir el ZIP recibido.
6. Arrastrar a GitHub los archivos de la carpeta `TP_Gastos_Interfaz`.
7. GitHub mostrará los archivos nuevos y los que reemplazan a los existentes.
8. En **Commit changes**, escribir por ejemplo:
   `Agregar interfaz gráfica y completar TP`
9. Elegir **Commit directly to the interfaz-grafica branch**.
10. Presionar **Commit changes**.

No seleccionar `main` durante este procedimiento.
