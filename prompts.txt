PROMPT 1
========

Prompt relevante (extracto):
"Necesito generar una interfaz para esa aplicación, usando la misma metodología
y el código más básico posible porque luego tengo que explicar el código."

Respuesta de IA:
Se propuso utilizar Tkinter para construir una interfaz gráfica sencilla y
mantener la solución basada en conceptos básicos de Python: funciones, listas,
diccionarios, condiciones y estructuras repetitivas.

Decisión tomada:
ACEPTADA CON MODIFICACIONES.

reorganizó el código en módulos para que cada archivo tuviera una
responsabilidad concreta.
